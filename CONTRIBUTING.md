QI New — Contribution Guidelines

Thank you for your interest in QI New!

1. Contact the maintainer first

Before preparing or submitting code changes, please contact the project maintainer on Instagram:

Instagram: [https://www.instagram.com/japons_20/]

Explain your idea and obtain the maintainer's written approval before proceeding with a code contribution.

2. No unauthorized changes to the official project

No external contributor is authorized to push changes directly to the official repository.

Only the project maintainer may approve and merge changes into the official project. All proposed changes are subject to review and may be rejected.

3. Suggestions and feedback

You are welcome to suggest new features, report bugs, and share improvement ideas.

Please contact the maintainer on Instagram before preparing code changes. You may also submit feedback through GitHub Issues if that feature is enabled.

4. Pull requests

Please do not submit a code-changing pull request without contacting the maintainer and receiving prior approval.

Submitting a pull request does not guarantee acceptance. The maintainer retains the final decision on whether proposed changes are incorporated into the official project.

5. Security and privacy

Never include API keys, passwords, access tokens, private user data, or other confidential information in issues, pull requests, screenshots, or source code.

6. Final decision

The maintainer retains control over the official QI New repository, its roadmap, and the changes accepted into the official project.

Thank you for respecting these guidelines and helping improve QI New!
